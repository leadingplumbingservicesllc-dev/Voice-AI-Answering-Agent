# Provider contract evidence

Reviewed 2026-10-23. No live account requests, calls or messages were made.

- Official installed **Twilio Node 6.2.0** types verified `VoiceResponse.connect().conversationRelay`, attributes `url`, `language`, `interruptible`, `welcomeGreeting`, Connect action, Gather DTMF, Calls fetch/update/list/page, Messages create/fetch/list and `validateRequest`/`getExpectedTwilioSignature`.
- Official Twilio sample [ai-phone-agent-conversation-relay-javascript](https://github.com/twilio-samples/ai-phone-agent-conversation-relay-javascript), commit `0ecf9a8fc8c4ee351ae3bd2ef55a97163b936f55`, was read from GitHub. Its README and `index.js` corroborate TwiML ConversationRelay, `setup.callSid`, `prompt.voicePrompt` / `last`, `interrupt.utteranceUntilInterrupt`, official OpenAI `chat.completions.create({stream:true})`, and outbound `text.token` / `last`. The implementation binds setup to the verified call/ticket; it does not require an undocumented setup `accountSid`. If accountSid or destination are provided, they must match. The authenticated inbound webhook and signed handshake establish account/number context.
- Official installed **OpenAI Node 7.43.0** types verified Chat Completions streaming, JSON schema response format, abort signals and `max_completion_tokens`. Candidate model `gpt-4.1-mini` requires live account verification; SDK types alone do not prove model access or pricing.
- Primary vendor web docs and pricing were attempted but returned network-policy HTTP 403. Official links are in DEPLOY.md/COSTS.md. The sample is corroborating evidence, not a substitute for checking the current full wire protocol and real provider behavior. In particular, WSS signature canonicalization, session ending/handoff, actual voice settings, account enablement, transcription quality, end-to-end latency, delivered callbacks, account limits and current prices remain launch gates.

No vendor sample's unsafe transcript logging, unrestricted tools or demonstration authentication is copied into this application. Default transport remains Twilio ConversationRelay only; no separate paid speech service is added. An alternative transport is documented only in ARCHITECTURE.md.
